# TOEIC Vol.5 / 2026 练习网站

ETS 토익 정기시험 기출문제집 5（2026）十套题的本地练习工具：对照 PDF 作答、自动判分、按题组播放听力、错题本、单词本、成绩记录。

纯静态网页，不需要构建，也没有后端。**题册 PDF 和 MP3 不在仓库里**，只在你自己的电脑上读取，不会上传。

## 使用

1. 解压资料包，得到 `TOEIC-2026-Vol5-10Tests/` 文件夹（Test-01 … Test-10）。
2. 打开网站，点 **选择资料文件夹**，选中这个文件夹。20 份题册和 540 段音频会一次载入。
   - Chrome / Edge 会记住这个文件夹。之后打开网站点一下“重新连接”就行，不用再逐个选择文件。
   - 其他浏览器每次刷新后需要重新选择一次文件夹。
3. 选择练习范围（阅读 100 题 / 全套 200 题），点一套开始。

### 练习时

| 按键 | 作用 |
| --- | --- |
| A–D 或 1–4 | 选择答案 |
| ← → | 上一题 / 下一题 |
| P（或空格） | 播放 / 暂停本题音频 |
| M | 标记难题 |

- **作答进度自动保存**：中途关掉页面，回到首页会提示“继续作答”。计时会暂停在离开时的位置。
- **播完自动下一段（模考）**：听力按顺序连续播放，自动跳到下一个题组。
- **阅读题选完自动跳下一题**：可选，适合 Part 5 快速刷题。
- 交卷后会把错题记入错题本，并在首页“成绩记录”留下本次正确题数、分项结果和用时。

## 换电脑

学习记录（错题、单词、成绩）保存在当前浏览器的 localStorage 里，不会自动同步。

换电脑前，在“错题本”页点 **导出学习备份**，把 JSON 带到另一台电脑，在同一网站点 **导入学习备份**。导入会合并记录，保留较新的条目。旧版网站导出的备份也能导入。

清除浏览器的网站数据会同时清除这些记录，请定期导出。

## 本地运行

```bash
python -m http.server 8080 --bind 127.0.0.1
```

然后打开 http://127.0.0.1:8080 。建议通过 HTTP 服务器或 GitHub Pages 打开，不要直接双击 `index.html`，否则浏览器可能不保留学习记录和文件夹授权。

## 部署到 GitHub Pages

仓库 Settings → Pages → Source 选 *Deploy from a branch*，分支选 `main`，目录选 `/ (root)`。几分钟后网站会出现在 `https://<用户名>.github.io/<仓库名>/`。

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` / `style.css` / `notebooks.css` | 页面与样式 |
| `app-2026.js` | 作答、计时、判分、分段音频 |
| `notebooks.js` | 错题本、单词本、成绩记录、备份导入导出 |
| `split-books.js` / `split-book-fingerprints.js` | 分套 PDF 的识别与 SHA-256 校验 |
| `materials.js` | 选择/记住资料文件夹 |
| `session.js` | 进度自动保存、快捷键、连续播放、成绩表 |
| `keys-ets2026.js` | 10 套 200 题答案 |

`.gitignore` 已经排除 PDF、MP3、ZIP 和学习备份 JSON，避免把受版权保护的资料或个人记录提交到仓库。

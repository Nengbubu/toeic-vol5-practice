# TOEIC Vol.5 / 2026 网站文件

现有网站：https://toeic-paper-practice.ivorystoat2.chatgpt.site/

本压缩包为网站代码，包含10套判分、分段音频播放器、错题本和单词本。题册与录音在另一个资料包 TOEIC-2026-Vol5-materials.zip，不在这个代码ZIP中。

## 使用

通过现有网站，或把解压后的文件放在自己的静态HTTP服务器根目录。安装Python的电脑可在该目录运行 python -m http.server 8080 --bind 127.0.0.1，然后打开 http://127.0.0.1:8080。

先解压资料包，按套导入 Test-xx-RC.pdf / Test-xx-LC.pdf；音频可用文件夹导入，也可在“分段音频ZIP”中选择完整资料ZIP，网页会读取其中的MP3。

错题本：交卷后自动记录实际答错的题；需要时勾选收录未答题。可写笔记、筛选、重做、标记已掌握；重做答对也会更新为已掌握。
单词本：保存单词/短语、释义、例句、笔记、来源套题和题号；支持搜索、编辑、掌握标记及遮住释义自测。

记录保存在当前浏览器（localStorage），不自动同步GitHub。换电脑时点“导出学习备份”，带走JSON，在另一台电脑同一网站“导入学习备份”。导入会合并，保留较新的条目；请定期备份，清除浏览器网站数据会清除本机记录。导出的JSON不包含题册和音频。
